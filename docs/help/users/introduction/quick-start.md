# Get started

Sign in to DXH Gateway. The first account owns the workspace. Add an MCP connection from the catalog or its remote URL, supply the service's credentials, and assign it to a profile. Connect your AI client to that profile using personal OAuth or your signed-in session.

CE allows 25 active accounts, one workspace and one saved REST/OpenAPI connection. Every role counts toward the account limit; inviting someone does not reserve a seat. Disabled REST connections still count.

Use tool permissions to block tools or require approval. Review activity and the security audit to see what happened. CE keeps at most seven days of history.
