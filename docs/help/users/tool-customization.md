# Tool permissions and approvals

Tool permissions are available in both editions. Allow a tool, require approval, or block it. A blocked tool cannot execute through the gateway. Approval is requested for an individual call according to the configured policy. Profile visibility can further restrict which tools appear.

Inspect the current tool set and manually review detected changes before widening access. EE can also check for tool/specification changes automatically. A change in the upstream API does not automatically grant new permissions.
