# Workspaces

A workspace groups its members, profiles, MCP servers, settings, and audit history. The active
workspace controls which resources you see and manage.

Single-workspace mode is the default. The first person to register owns the shared workspace and
later admitted users join as members. The **Workspace** page keeps member, invitation, auto-join
domain, management-key, and audit controls available, and shows a copyable immutable Workspace ID.

Multi-workspace deployments let owners create and switch workspaces. The legacy `/organization` URL
continues to redirect to `/workspace` for existing bookmarks.
